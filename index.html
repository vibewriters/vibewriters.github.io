2.1 가계부 앱 생성 
가계부 앱을 만들어줘.

기능:
- 거래 입력 (수입·지출·저축 구분)
- 카테고리별 분류 (식비, 교통, 주거, 의료, 쇼핑, 여가, 기타)
- 월별 내역 조회
- 월별 통계 (총 수입, 총 지출, 카테고리별 금액)

화면 구성(레이아웃)은 이렇게 해줘. 좌우 2단이야.
- 왼쪽 패널(입력): 맨 위 주황색 카드에 지출/수입/저축 토글과 큰 금액 입력칸. 그 아래 '결제 문자 붙여넣기' 텍스트칸(지금은 빈 칸으로 두고, 자동 입력 기능은 나중에 붙임), 날짜([오늘][어제] + 날짜 선택기), 가맹점/내용, 카테고리·결제수단·소유자 드롭다운, 메모, 맨 아래 큰 주황색 [저장] 버튼.
- 오른쪽 패널(보기): 거래 내역을 목록으로 크게 보여줘. 이 목록이 오른쪽의 대부분을 차지해. 목록 위에는 검색창과 필터(기간·카테고리·수입/지출), 그리고 월 이동(◀ 2026년 6월 ▶)을 넣어줘. 월 이동은 화면 맨 위 가운데가 아니라 이 오른쪽 패널 위에 둬. 맨 아래에는 이번 달 수입·지출·저축·잔액을 얇은 한 줄로 요약해줘. (큰 통계 블록을 위쪽에 만들지 마. 요약은 아래 한 줄이면 돼.)
- 색감: 주황색을 포인트로, 나머지는 흰 배경에 파스텔. 카드는 둥근 모서리로.
- 모든 금액은 천단위마다 콤마를 넣은 '원' 단위로 통일해서 보여줘. (예: 70,370원 / 1,234,000원) '만'·'억' 같은 축약 단위로 바꾸지 말고, 화면 어디서나 같은 형식으로 적용해줘.
- 지금은 이 기능만 만들고, 앞으로 기능을 더할 때 화면 위쪽에 탭을 하나씩 추가할 거야. 그러니 탭을 나중에 붙이기 쉬운 구조로 만들어줘. (지금 없는 탭은 미리 만들지 마.)

데이터베이스는 수파베이스를 사용해줘.

2.2 신용카드 문자 자동 입력 
카드 결제 문자를 붙여넣으면 자동으로 거래를 입력하는 기능을 만들어줘.

- 앞에서 만든 '결제 문자 붙여넣기' 칸에 카드 문자를 붙여넣으면 자동으로 폼이 채워지게 해줘.
- 앱을 열었을 때 클립보드에 결제 문자가 있으면 상단에 "복사한 결제 내역이 있어요" 배너를 띄우고, [붙여넣기]를 누르면 그 칸에 넣어줘.
- 문자에서 가맹점·금액·날짜를 자동으로 뽑아 입력 폼에 채워줘.
- 국내 주요 카드사 문자 형식을 인식해줘.
  (KB국민, 신한, 삼성, 현대, 롯데, 하나, 우리BC, 농협, 씨티, 카카오페이, 카카오뱅크, 토스뱅크 등)
- 누적금액·잔액은 거래 금액으로 오인하지 않게 걸러줘.
- 잘못 뽑히거나 빠진 값이 있으면 그 칸만 직접 고칠 수 있게 해줘.
- 가맹점명으로 카테고리를 자동 추천해줘. (예: 스타벅스→식비, GS25→쇼핑)
- 한 가맹점에 내가 카테고리를 한 번 골라주면, 그 선택을 기억해서
  다음에 같은 가맹점이 들어오면 그 카테고리를 자동으로 채워줘.
- 그래서 자주 가는 곳은 내가 확인만 하고 [저장]을 누르면 끝나게 해줘.

새 데이터를 저장할 테이블이 필요하면 SQL을 알려줘.

CSV 파일로 과거 거래를 한 번에 가져오는 기능을 만들어줘.

2.5 날짜별 달력 보기 
오른쪽 내역 목록 위에 [목록] / [달력] 토글을 만들고, 달력 보기를 추가해줘. 달력이 오른쪽의 대부분을 차지하게 크게 만들어줘. 앱을 열면 달력이 기본으로 보이게 해줘. (목록이 아니라 달력이 먼저.)

- 월 달력의 각 날짜에 그날의 지출·수입·저축을 함께 표시해줘. 지출은 빨강(예: -12,000원), 수입은 파랑(예: +100,000원), 저축도 구분되는 색으로.
- 지출이 많은 날은 칸을 진한 색으로 칠해줘(히트맵).
- 날짜를 누르면 그날의 거래를 지출·수입·저축으로 나눠 자세히 보여줘.
- 지난 달로 넘겨서 과거 날짜도 볼 수 있게 해줘.
- 금액은 '만' 단위로 줄이지 말고 천단위 콤마를 넣은 원 단위로 보여줘.

3.3 재무 건전성 점검 
사이드바에 '재무 건전성' 탭을 추가해줘. 자산·부채는 이 앱 데이터를 쓰고,
월 수입·지출·저축은 가계부 앱 수파베이스에 연결해 최근 3개월 평균으로
계산해줘.

가계부 수파베이스 URL: [가계부 앱 수파베이스 URL]
가계부 Publishable key: [가계부 앱 Publishable key]

- 네 가지 지표를 카드로 보여줘. 각 카드에 쉬운 이름과 값, 그리고
  초록·노랑·빨강 신호등을 붙여줘:
  1) 저축률 = 월 저축·투자액 ÷ 월 수입
     (20% 이상 초록 / 10~20% 노랑 / 10% 미만 빨강)
  2) 비상금 개월 수 = 현금성 자산(예금·현금) ÷ 월 지출
     (6개월 이상 초록 / 3~6개월 노랑 / 3개월 미만 빨강)
  3) 부채비율 = 총부채 ÷ 총자산
     (40% 미만 초록 / 40~60% 노랑 / 60% 이상 빨강)
  4) 유동성 비율 = 현금성 자산 ÷ 총자산
     (30% 이상 초록 / 10~30% 노랑 / 10% 미만 빨강)
- 네 지표를 묶어 '금융 건강 점수'를 0~100점으로 한 줄 요약해줘.
- 가장 약한(빨강 먼저, 그다음 노랑) 지표를 골라 "지금 먼저 챙길 것"을
  한 문장으로 알려줘.
- 어려운 용어 대신 쉬운 이름을 쓰고, 각 지표 옆에 한 줄 설명을 달아줘.
- 자산·부채나 가계부 거래가 바뀌면 이 점수도 자동으로 다시 계산해줘.
3.4 대출·상환 계획 
사이드바에 '대출' 탭을 추가해줘. 대출 상환 계획 화면을 만들어줘.

- 대출을 등록할 수 있게 해줘 (이름, 잔액, 금리, 상환 방식, 남은 개월 수).
- 상환 방식은 원리금균등 / 원금균등 / 만기일시로 구분해줘.
- 매달 나가는 상환액을 원금과 이자로 나눠서 보여줘.
- 만기까지 낼 총 이자를 보여줘.
- 중도상환 금액을 넣으면, 줄어드는 총 이자와 단축되는 기간을 계산해줘.
- 상환 스케줄에 따라 매달 원금·이자·잔여 대출 잔액이 자동으로 갱신해줘.
  (매달 손으로 고치지 않아도 날짜가 지나면 반영되게)
- 대출 잔액이 줄면 순자산에 자동으로 반영해줘. 주택담보대출처럼 특정 자산에
  묶인 대출은 그 자산(부동산)의 순가치에 연동해줘.
- 금액은 천단위 콤마를 넣은 원 단위로 보여줘.

대출·상환 스케줄을 저장할 테이블이 필요하면 SQL도 알려줘.
3.5 포트폴리오 입력 
사이드바에 '포트폴리오' 탭을 추가해줘. 투자 포트폴리오 화면을 만들어줘.

- 종목을 등록할 수 있게 해줘 (종목명 또는 종목코드, 수량, 매입 단가, 매입일).
- 같은 종목을 여러 번 사면 평균 매입 단가를 자동으로 계산해줘.
- 주식 / 펀드 / 코인 / 외화 종류를 구분해줘.
- 종목별 매입 금액(수량 × 평균 매입 단가)과 전체 포트폴리오에서의 비중을 보여줘.
- 금액은 천단위 콤마를 넣은 원 단위로 보여줘.

포트폴리오를 저장할 테이블이 필요하면 SQL을 알려줘.
3.6 시세 자동 갱신 
포트폴리오 종목의 현재 시세를 자동으로 가져와 평가액을 갱신해줘.

- 주식·코인·환율은 무료로 쓸 수 있는 시세 소스에서 가져와줘.
- 실시간이 아니어도 되니, 하루 한두 번 갱신되는 방식이면 돼.
- 종목마다 매입가 대비 현재 평가액을 보여줘.
- 달러 자산은 환율을 반영해 원화 평가액으로도 보여줘.
- 시세를 못 가져오는 종목은 마지막으로 받은 값을 유지하고, 그 옆에
  마지막 갱신 시각을 표시해줘.
- 시세가 갱신되면 순자산과 포트폴리오 비중도 자동으로 다시 계산해줘.
3.7 손익·수익률 
'포트폴리오' 탭에 손익·수익률을 함께 보여줘.

- 종목마다 평가손익(현재 평가액 − 매입 금액)을 금액과 수익률(%)로 보여줘.
- 이익은 초록, 손실은 빨강으로 색을 구분해줘. (앞에서 만든 화면들과 같은 기준)
- 포트폴리오 전체 합계 손익과 전체 수익률도 맨 위에 보여줘.
- 배당을 받은 종목은 배당금을 따로 기록하고, 손익에 더해서 보여줘.
- 금액은 천단위 콤마를 넣은 원 단위로 보여줘.
3.8 투자성향 분석 
사이드바에 '투자성향' 탭을 추가해줘. 투자성향 분석 기능을 만들어줘.

- 투자성향을 파악하는 질문을 5~7개 넣어줘 (투자 기간, 손실을 견디는 정도,
  기대 수익, 투자 경험 등). 객관식으로 답하게 해줘.
- 답을 합산해 성향을 판정해줘: 안정형 / 안정추구형 / 위험중립형 /
  적극투자형 / 공격투자형.
- 성향에 맞는 권장 자산 배분(주식 / 채권 / 현금 비율)을 제안해줘.
- 특정 종목 추천은 하지 말고, 자산군 배분 수준까지만 안내해줘.
- '이 배분을 목표로 저장' 버튼을 넣어서, 리밸런싱 화면의 목표 비중으로 넘겨줘.
3.9 리밸런싱 제언 
사이드바에 '리밸런싱' 탭을 추가해줘. 포트폴리오 리밸런싱을 도와줘.

- 자산군별 목표 비중을 내가 정할 수 있게 해줘 (예: 주식 60 / 채권 20 / 현금 20).
- 현재 비중과 목표 비중을 나란히 막대로 보여줘.
- 목표와의 차이(초과·부족)를 금액과 퍼센트로 보여줘.
- 어느 자산군을 얼마나 줄이고 늘리면 목표에 맞는지 문장으로 제안해줘.
- 금액은 천단위 콤마를 넣은 원 단위로 보여줘.
3.10 생애 설계 입력값 연동 
사이드바에 '생애 설계' 탭을 추가해줘. 생애 재무 설계 화면을 만들고, 입력값은 최대한 기존 데이터에서 끌어와줘.

- 자산 앱의 현재 순자산과 자산 구성을 불러와 기본값으로 채워줘.
- 재무 건전성에서 연결한 가계부의 최근 6개월 평균 월 지출·수입·저축액을
  불러와 채워줘.
- 내가 직접 넣는 값은 은퇴 나이, 은퇴 후 예상 월 지출, 연금 수령 시작 나이,
  예상 연 수익률로 최소화해줘.
- 끌어온 값과 직접 넣는 값을 한 화면에서 확인·수정할 수 있게 해줘.
3.11 성장 곡선·핵심 지표 
생애 재무 설계에 순자산 성장 곡선과 핵심 지표를 그려줘.

- 지금부터 기대 수명(예: 만 85세)까지 순자산 곡선을 그려줘.
- 곡선에 은퇴 시점과 연금 시작 시점을 세로선으로 표시해줘.
- 요약 지표 네 가지를 카드로 보여줘:
  은퇴 시점 순자산 / 경제적 자유 시점(패시브 소득 ≥ 지출) /
  고갈 위험(기대 수명 전에 자산이 바닥나는지) / 최종 순자산.
- 금액은 억·천단위 콤마로 읽기 쉽게 보여줘.
3.12 시나리오 비교 
생애 재무 설계에 시나리오 비교를 넣어줘.

- 시나리오 버튼: 은퇴 5년 앞당기기 / 자녀 1명 추가 / 경제 위기 발생 / 절약.
- 버튼을 누르면 그 조건으로 곡선과 네 지표를 즉시 다시 계산해줘.
- 기본 시나리오와 선택한 시나리오를 곡선에서 겹쳐 비교할 수 있게 해줘.
- 직접 수정 버튼을 눌러 은퇴 나이·저축액 등을 손으로 바꿔볼 수도 있게 해줘.
3.13 생애 설계 월 1회 자동 갱신 
생애 재무 설계를 자동으로 갱신해줘.

- 매달 초에 한 번 최신 자산 데이터로 생애 설계를 다시 계산해줘.
- 최신 순자산과 가계부 최근 지출·수입을 다시 끌어와 곡선과 지표를 갱신해줘.
- 마지막으로 갱신된 날짜를 화면에 표시해줘.
3.14 자산 목표·위시리스트 
사이드바에 '목표·위시리스트' 탭을 추가해줘. 자산 목표와 위시리스트, 알림 기능을 만들어줘.

- 목표를 등록할 수 있게 해줘 (이름, 목표 금액, 목표일, 종류: 자산 목표 / 위시리스트).
  위시리스트 예: 유럽 여행 500만 원, 명품 가방 300만 원.
- 목표마다 연결할 적금을 고를 수 있게 해줘. 자산관리에 등록된 그 적금 잔액이
  늘면 목표 진행률도 자동으로 올라가게 해줘.
- 목표마다 현재 도달률(%)을 막대로 보여주고, 지금 저축 속도면 언제 완료되는지
  예상 날짜를 보여줘.
- 부족하면 매달 얼마를 더 넣어야 목표일에 닿는지 계산해줘.
- 다음 상황에서 화면 위쪽에 알림을 띄워줘:
  목표 도달률 90% 도달 / 순자산이 한 달 새 큰 폭으로 변동 /
  포트폴리오 비중이 목표에서 크게 벗어남.
- 금액은 천단위 콤마를 넣은 원 단위로 보여줘.

목표·위시리스트를 저장할 테이블이 필요하면 SQL도 알려줘.
3.15 월말 자산 리포트 
사이드바에 '월말 리포트' 탭을 추가해줘. 월말 자산 리포트 화면을 만들어줘.

- 이번 달 순자산이 지난달 대비 얼마 늘거나 줄었는지 금액과 퍼센트로 보여줘.
- 그 변화를 요인별로 나눠줘: 새로 저축·투자한 돈 / 투자 평가손익 /
  환율 변동 / 부채 상환.
- 한 화면에 이번 달 요약을 정리해줘.
- 월별로 순자산과 요인을 비교해 볼 수 있게 해줘.
- 금액은 천단위 콤마를 넣은 원 단위로 보여줘.
3.16 가족 공유 
가족이 함께 쓰는 기능을 만들어줘.

- 설정 화면에 '가족 공유'를 만들고, 초대 코드(또는 초대 링크)를 만들 수 있게 해줘.
- 배우자·가족은 그 코드로 같은 자산 공간에 들어와.
- 설정 화면에 지금 함께 쓰는 구성원 목록과 참여 상태를 보여줘.
- 한 사람이 자산을 등록·수정하면 다른 사람 화면에도 반영돼.
- 소유자별(나 / 배우자 / 공동) 순자산은 그대로 나눠 볼 수 있게 유지해줘.

수파베이스의 실시간(Realtime) 기능을 사용해줘.

가족 공유에 필요한 테이블·설정 SQL도 알려줘.
3.17 로그인·보안 붙이기 
이 앱에 로그인을 붙여줘.

- 이메일로 회원가입·로그인하게 해줘. 수파베이스 인증(Authentication)을 사용해줘.
- 로그인한 사용자와 초대받은 가족만 자산 데이터를 볼 수 있게 해줘.
- 로그인 안 한 사람은 데이터에 접근하지 못하게 막아줘.
- 데이터베이스에도 RLS 정책을 걸어서, 본인과 초대받은 가족만 데이터를 읽고 쓸 수 있게 잠가줘.

4.1 건강관리 앱 생성

4.2 음성으로 식단 기록 
식단 입력에 '음성 AI' 탭을 추가해줘.

4.3 먹는 순서·양 추천 
음식 분석 결과에 '먹는 순서'와 '양 조절 팁'을 추가해줘.

- 먹는 순서는 번호를 붙인 카드로, 양 조절 팁은 그 아래 한 줄로 보여줘.
4.4 러닝 기록 탭 추가 
러닝 전용 기록 탭을 추가해줘.

입력 항목:
- 날짜, 거리(km), 소요 시간 → 페이스(분/km) 자동 계산
- 코스 메모 (동네 한 바퀴, 한강 코스 등)
- 날씨 선택 (맑음 / 흐림 / 비)

통계 화면:
- 이번 달 누적 거리 (예: 47.3km / 목표 100km 진행 바)
- 이번 주 평균 페이스
- 최근 5회 페이스 트렌드 차트 (빨라지는지 느려지는지)
- 월별 마일리지 히스토리 (막대 그래프)

기존 운동 기록과 분리해서 러닝 전용 탭으로 만들어줘.
러닝 기록을 저장할 테이블이 필요하면 SQL을 알려줘.

  기초대사량(BMR)과 TDEE를 계산해줘. (미플린-세인트 지어 공식)
